# Glossary

Reference material for players and re-enactors. The vocabulary, commands,
and historical context of The Earl of Loudoun's Regiment of Foote and the
Wars of the Three Kingdoms (1638–1651).

Each entry is short and period-accurate. The glossary grows as new
content surfaces in-game.

## Contents

- [**terms.md**](terms.md) — Period vocabulary. Kit, ranks, formation
  structure, currencies, mechanics — what every word means.
- [**drill-commands.md**](drill-commands.md) — The drill manual. Every
  pike command, how the soldier physically performs it, and when it's
  used.
